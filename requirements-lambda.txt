# Two deliberate absences. psycopg is missing because the deployed server never speaks to
# Postgres directly — server/db.py imports it inside LocalBackend precisely so the aws

# runtime already provides it; shipping a second copy costs package size and pins the
# deployed version to whatever this file says rather than what AWS maintains.
#
# Versions are the same pins as requirements.txt and have to stay that way: the whole
# point of the two-backend seam is that the deployed server is the same server.
